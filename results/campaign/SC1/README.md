# SC1, static mining on `D_init`

Eight databases, six algorithms (USpan, HUSP-ULL, HUSP-SP, IncUSP-Miner+, Pre-HUSPM and Pre-HUSPM-Adaptive), four thresholds per database from `common.Datasets`. One JVM per arm; the four thresholds run lowest first in the same JVM.

No arm of this scenario has finished yet. Its tables are written here from the arms' CSVs by
`analysis/scenario_readmes.py` once they have: `.\campaign.ps1 -Scenario SC1`.
