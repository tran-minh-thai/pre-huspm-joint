# SC1 memory: the live set of a static mine on `D_init`

The runs of SC1 measured for memory instead of time: at every sample the runner forces a full collection and reads the heap right after, so runtimes are void.

No arm of this scenario has finished yet. Its tables are written here from the arms' CSVs by
`analysis/scenario_readmes.py` once they have: `.\campaign.ps1 -Scenario SC1`.
